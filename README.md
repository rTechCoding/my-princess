# my-princess

Key Features & UI Components
1. Interactive 3D Heart Canvas & Ambient Atmosphere
Heart Particle Engine: Floating 3D-like particle heart formed by hundreds of glowing pink/red/gold particles pulsing in sync with a soft heartbeat.
Floating Rose Petals & Stars: Physics-based gentle petal drift reacting to mouse/touch movement.
Glassmorphism Theme: Deep romantic dark gradient background (#0d0211 to #2a0826) with glowing neon accents and frosted glass containers.
2. Animated Romantic Text & Story Sequence
Typewriter Story Engine: Sequential romantic narrative unveiling love letters step-by-step with glowing typography (Great Vibes & Outfit Google Fonts).
Interactive Love Counter: Real-time ticker displaying days, hours, minutes, seconds of togetherness or anticipation.
3. Playful Proposal Card ("Will You Be Mine?")
Centerpiece Glass Card: Heartbeat animation around the main proposal question.
Interactive Buttons:
"YES! 💖": Unlocks the grand celebration (fireworks, heart confetti burst, romantic synth chorus, love certificate modal).
Playful "NO 😜" Button: Evasive runaway logic that playfully moves away when hovered or tapped, displaying funny romantic prompts ("Are you sure? 🥺", "Try again! 💓", "Nice try! 😉").
4. Interactive Photo Gallery & Memory Timeline
3D tilted Polaroid photo cards with romantic captions, hover shine effects, and customizable images.
5. Web Audio Romance Soundscape & Controls
Procedural Web Audio API sound generator (Soft romantic piano chords, gentle heartbeat bass, chime bells) for zero-dependency ambient sound that plays reliably in all browsers.
Mute/Unmute audio floating control.
6. Live Customizer Modal & Shareable State
Side drawer allowing users to customize:
Partner's Name & Proposer's Name
Custom Proposal Message & Love Story Chapter texts
Proposal Date
Custom Photo URLs
Saves settings to localStorage and generates a shareable URL hash so the proposal can be sent to the partner.
